강화와 훈련

강화 확률에 도전하고, 라인업 밖 카드를 재료로 훈련하세요.

강화 최대 +10 · 훈련은 카드별

카드 강화

누적 0.5마다 우선 3개 능력치가 각각 +1 올라 OVR이 +0.5가 됩니다. 다음 0.5가 쌓이면 전체 능력치가 +1 됩니다.

ENHANCE

강화할 카드 선택

100%
+0에서 +1 강화성공 시 전체 또는 우선 스탯에 능력치가 더해집니다.

강화 확률은 룰 시트 기준입니다: 0→1 100%, 이후 단계마다 80%, 75%, 60%, 45%, 35%, 25%, 20%, 15%, 10%입니다. 0.5+0.5는 누적 전체 +1과 같습니다. 실패하면 강화 단계가 1 하락합니다. +0에서는 유지됩니다.

선택 0장 · 0 별

훈련은 카드 별 수×6레벨까지 가능합니다. 한 레벨에 카드 별 수×4 훈련 별이 필요하며, 각 레벨마다 지정 능력치가 +2 상승합니다. 능력치는 구속·구위·지구력·변화·제구·수비 순서로 오릅니다. 마지막 재료는 최대 레벨까지 남은 별만 반영되고, 초과 별은 적용되지 않습니다.

BACKUP
게임은 현재 브라우저에 자동 저장됩니다. 다른 기기로 옮기려면 이 기기에서 텍스트 파일을 저장한 뒤, 새 기기에서 파일을 불러와 복원하세요. 백업에는 보유 카드 전체가 포함됩니다.

복원하면 이 기기에 저장된 진행 상황이 백업 내용으로 바뀝니다. 다른 기기에서 내보낸 백업 파일을 그대로 선택하거나, 백업 내용을 붙여넣은 뒤 복원하세요. 이전 버전의 일반 JSON 텍스트 백업도 그대로 불러올 수 있습니다.
